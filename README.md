Sebas Crypto Paper Trading Bot v1.0

Live Bitcoin paper trading bot built in Nairobi, KE. Polls CoinGecko every 10s, paper-trades only, logs everything to CSV, and plots P/L.

Features
- Live price feed from CoinGecko API
- Paper trading logic: BUY on 0.2% dip, SELL on 0.3% gain
- Append-only logging to `trades.csv` (timestamp, event, price, balance, pnl)
- Telegram alert stub ready for future
- Matplotlib profit chart via `plot_prof Kisii - from 451 blocked to live bot in 1 day.
